# Krishi-Vani: AI for Rural Innovation
**Hackathon Track:** AI for Rural Innovation & Sustainable Systems

## Project Overview
Krishi-Vani is a voice-first intelligence platform designed for Bharat's farmers. It uses on-device SLMs and Indic-Whisper to bridge the information gap in Mandi pricing and crop diagnostics.

## Tech Stack
- **AI/ML:** AWS Bedrock, Phi-3 (Quantized), Indic-Whisper
- **Data Pipeline:** Time-Series Forecasting (LSTM) for price prediction
- **Deployment:** Edge-Cloud Hybrid architecture
